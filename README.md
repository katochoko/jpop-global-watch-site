# J-POP Global Watch

日本の音楽の世界各地での広がりを調べる、公開用のウェブアプリです。

この保存先にはブラウザーへ配信するHTML・CSS・JavaScriptだけを配置しています。開発用の保存先・検証ファイル・開発履歴は別に管理しています。

観測ノートやレポートは、閲覧者それぞれのブラウザー内に保存します。他の人と共有・同期する機能はありません。定期的にアプリからバックアップしてください。

現在はチャートへのリンク、手動の観測記録、レポート保存を使う初期版です。ランキングの自動収集・毎週のAI自動分析・サーバー側の保存は未接続です。架空のランキングは入れていません。
